# Licensing Strategy

## Community Edition: Apache 2.0

The core OpenClaw code + enterprise overlay is Apache 2.0 licensed.

**What users can do:**
- Use commercially (run their own agency)
- Modify for their needs
- Distribute to their team
- Submit pull requests
- Build plugins/extensions

**What users cannot do (without Pro/Enterprise license):**
- Remove copyright notices
- Use "OpenClaw" trademark without permission
- Resell the SaaS platform to others (multi-tenant SaaS requires commercial license)

**Files covered:** All files in `src/`, `extensions/`, `ui/`, `packages/` except Pro/Enterprise-specific features gated behind license checks.

## Pro Edition: Source-Available License

Modified Apache 2.0 with additional restrictions:

**What Pro license holders can do:**
- Everything in Community
- Access Pro features (dashboard, multi-tenant, WhatsApp API, CRM connectors)
- Modify for internal use
- Self-host for their organization

**Restrictions:**
- Cannot resell as SaaS to third parties (SaaS rights = Enterprise)
- Cannot remove license checks
- Must maintain attribution
- Annual renewal for self-hosted ($999/year)

**License file location:** `LICENSE-PRO.md` in repository

## Enterprise Edition: Commercial License

Bespoke license negotiated per customer:

**Standard terms:**
- Perpetual or annual license
- SaaS hosting rights (resell to your customers)
- White-label rights (rebrand as your own product)
- Custom modifications allowed
- Source code access under NDA
- Support and SLA included

**Pricing models:**
1. **SaaS Revenue Share**: 15-20% of MRR generated by customer
2. **Per-User License**: $50-200/user/year
3. **Flat Annual**: $5K-50K/year based on size
4. **Custom Negotiation**: For large deals (franchises, portals)

## License Enforcement (Technical)

### Self-Hosted License Key

```typescript
// src/enterprise/licensing/license-check.ts
interface License {
  tier: 'community' | 'pro' | 'enterprise';
  maxUsers: number;
  maxTenants: number;
  features: string[];
  expiresAt: Date;
  signature: string;  // RSA signature
}

export function verifyLicense(licenseKey: string, publicKey: string): License {
  const [payload, signature] = licenseKey.split('.');
  const decoded = JSON.parse(Buffer.from(payload, 'base64').toString());

  const verifier = createVerify('RSA-SHA256');
  verifier.update(payload);
  const valid = verifier.verify(publicKey, signature, 'base64');

  if (!valid) throw new LicenseInvalidError();
  if (new Date(decoded.expiresAt) < new Date()) throw new LicenseExpiredError();

  return decoded;
}
```

### Feature Gating

```typescript
// In feature code
const license = await getLicense(ctx.tenantId);

if (!license.features.includes('crm_sync')) {
  throw new FeatureNotLicensedError('CRM sync requires Pro or Enterprise license');
}

if (license.tier === 'community' && currentUsers >= 1) {
  throw new LicenseLimitError('Community edition limited to 1 user');
}

if (license.tier === 'pro' && currentUsers >= license.maxUsers) {
  throw new LicenseLimitError(`Pro edition limited to ${license.maxUsers} users`);
}
```

### SaaS License Check

SaaS deployment doesn't need license keys — billing is handled by Stripe/Razorpay subscription status.

```typescript
if (process.env.DEPLOYMENT_MODE === 'saas') {
  // Check subscription status from billing service
  const subscription = await billing.getSubscription(ctx.tenantId);
  return {
    tier: subscription.plan,
    maxUsers: PLANS[subscription.plan].maxUsers,
    features: PLANS[subscription.plan].features,
  };
}
```

## Legal Considerations

1. **India**: GST 18% on SaaS fees. Export to foreign customers = 0% GST.
2. **USA**: Sales tax varies by state. Use Stripe Tax for automatic calculation.
3. **EU**: VAT MOSS for B2C, reverse charge for B2B.
4. **Trademark**: Register "OpenClaw TeamOS" in India, USA, EU.
5. **Open Source Compliance**: Ensure all third-party dependencies are Apache/MIT/BSD compatible.
